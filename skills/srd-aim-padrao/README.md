# SRD em padrão compacto

Cria solicitações de reembolso prontas para conferência, reunindo formulário e comprovantes em um PDF. Também pode manter planilha histórica.

## Aplicabilidades

- materiais, transporte, hospedagem, alimentação e serviços;
- separação por colaborador, projeto ou finalidade;
- comprovantes na ordem dos itens;
- controle mensal de números, valores e status.

## Exemplo

> Use `$srd-aim-padrao` para preparar duas SRDs, transporte e hospedagem. Use os anexos como comprovantes e deixe assinaturas em branco.

## Requisitos e privacidade

Forneça modelo autorizado, dados do solicitante, projeto, data, número, pagamento, itens e comprovantes. Identidade visual só deve ser redistribuída com autorização. Trabalhe com documentos pessoais e financeiros apenas em área privada.
