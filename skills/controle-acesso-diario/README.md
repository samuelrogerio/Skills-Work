# Controle de acesso diário

Transforma folha de acesso digitalizada, fotografada ou em PDF em relatório de presença com totais conferidos.

## Aplicabilidades

- fechamento diário de efetivo;
- entradas e saídas por empresa;
- contagem por função;
- transcrição manuscrita com dúvidas sinalizadas.

Não serve para marcar presença por lista sem horário nem para completar dados por estimativa.

## Exemplo

> Use `$controle-acesso-diario` nas duas páginas anexadas. Considere presente apenas quem tiver entrada marcada e destaque as saídas.

## Cuidados

Folhas de acesso contêm dados pessoais. Não as versione no Git e não use nomes reais em exemplos.
